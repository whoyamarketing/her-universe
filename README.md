# Твоя вселенная

Интерактивный сайт-подарок: Человек-паук, Коноха, Готэм, магический лес, мир Эрена Йегера, ферма Буббы Сойера, сцена Бритни Спирс, музыкальный мир Lil Peep / 50 Cent / Oxxxymiron, дорога братьев Винчестеров и личное послание. Статический HTML/CSS/JavaScript без сборки, сторонних библиотек и внешних запросов.

## Локальный просмотр без сервера (Chrome)

1. На GitHub выберите ветку `main`, затем **Code → Download ZIP**.
2. Полностью распакуйте ZIP в обычную папку на компьютере.
3. Откройте `index.html` двойным щелчком или через **Открыть с помощью → Google Chrome**.

Сохраняйте `index.html`, `styles.css`, `characters.js`, `app.js` и папку `assets` вместе. Установка Node.js, Python, пакетов или запуск сервера не нужны. Сайт использует обычные скрипты и относительные пути, без модулей, `fetch` и внешних ресурсов. Звук включается кнопкой после открытия страницы. Если компьютер управляется организацией, её политики Chrome могут запрещать адреса `file://`.

## Необязательный запуск через сервер

```sh
cd /workspace/her-universe
python3 -m http.server 8000 --bind 0.0.0.0
```

На своём компьютере откройте http://localhost:8000. В облачной среде используйте доступный механизм перенаправления порта 8000. Если его нет, скачайте проект и запустите команду локально. Также можно открыть `index.html` напрямую.

## Редактирование

- `characters.js`: фразы героев, пути к изображениям и `personalMessage` — личное послание.
- `index.html`: композиция и текст сцен. Для нового героя добавьте `<div class="character" data-character="new-id"></div>` в нужную сцену и соответствующую запись в `characters.js`.
- `styles.css`: цвета, расположение, мобильная версия и анимации. Для нового героя задайте позицию селектором `[data-character="new-id"]`.
- `app.js`: взаимодействия, эффекты, звук и параллакс.
- `assets/characters/`: оригинальные упрощённые SVG-заглушки, созданные для прототипа, без заимствования чужих изображений. Фоны и декорации нарисованы CSS. Это стилизации, а не официальные изображения персонажей.
- `assets/scenes/`: место для будущих фоновых иллюстраций. При замене используйте свои или лицензированные изображения; для растровых файлов предпочтительны WebP/AVIF с разумным разрешением.

Клик или Enter/пробел на герое показывает очередную фразу и эффект. Escape закрывает фразу. Звук выключен по умолчанию; кнопка включает короткие синтезированные ноты при взаимодействиях, без загрузки аудио. Системная настройка уменьшения движения отключает анимации и плавную прокрутку.

Каждая облачная задача уже изолирована: используйте существующий checkout, дополнительный Git worktree не нужен.

## Онлайн-просмотр через GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment**:

- Source: **Deploy from a branch**.
- Branch: **main**, папка **/ (root)**, затем **Save**.

После успешного развёртывания сайт будет доступен по адресу https://whoyamarketing.github.io/her-universe/ . Последующие коммиты в `main` автоматически обновляют сайт; публикация обычно занимает несколько минут. Статус доступен в разделе **Actions**. Файл `.nojekyll` отключает ненужную обработку Jekyll. Не добавляйте в репозиторий секреты или тексты, которые не хотите публиковать.

Новые реплики музыкальных исполнителей и Винчестеров — вымышленные фразы для подарочного сайта, не цитаты. Музыка исполнителей не загружается: кнопка звука включает только синтезированные ноты.

В общих сценах также доступны Орочимару (Коноха), Беллатриса Лестрейндж (магический лес) и Леви Аккерман (Атака титанов). Их изображения и вымышленные реплики редактируются в `characters.js`.

Сцена «Крик» с Ghostface находится сразу после фермы Буббы Сойера. Иллюстрация — `assets/characters/ghostface.svg`, реплики — запись `ghostface` в `characters.js`.

Честер Беннингтон присоединяется к общей музыкальной сцене, Кроули — к Винчестерам. Их реплики вымышлены для подарочного сайта и не являются цитатами.

Текущий состав музыкального мира: Lil Peep, 50 Cent, Oxxxymiron и Честер Беннингтон. Реплики вымышлены для сайта и не являются цитатами исполнителей.

Вселенная Dudu находится перед финальным посланием. По нажатию мишка всегда говорит `My Motka Bubu` и показывает сердечки. Векторная иллюстрация создана по присланному визуальному образцу; путь и фраза задаются записью `dudu` в `characters.js`.

Бензопила Буббы: нажатие включает анимацию рук и загруженную запись `assets/audio/chainsaw.mp3` (громкость 65%). Повторное нажатие, Escape, отключение звука, уход из сцены или скрытие вкладки останавливают действие. Запись заканчивается без зацикливания. Прямое нажатие на Буббу включает общий звук. При уменьшении движения используется статичное изображение. Активная иллюстрация — `assets/characters/bubba-active.svg`.

Телефон Ghostface: при появлении сцены и включённом общем звуке зацикливается `assets/audio/phone-ring.mp3`. Нажатие на телефон прекращает звонок и запускает `assets/audio/ghostface-hello.mp3`; повторное нажатие останавливает голос. Клик на телефон сам включает звук. До первого взаимодействия браузер может блокировать автоматический звонок. Уход из сцены, скрытие вкладки, Escape и отключение звука останавливают запись. Пути редактируются в `phone` файла `characters.js`.

Поздравления: кнопка сообщений рядом со звуком открывает телефонный чат. По одному поздравлению от каждого персонажа в порядке сцен; тексты — поле `birthday` в `characters.js`. Счётчик вычисляется по уникальным героям на странице. Сообщения появляются каждые 4,2 секунды, кнопка «Следующее сообщение» ускоряет показ. Закрытие окна и скрытие вкладки приостанавливают очередь. Прочитанные поздравления сохраняются локально в браузере; при недоступном хранилище — до перезагрузки. Управление чатом — `messages.js`. Поздравления вымышлены, не являются реальными сообщениями или цитатами.
